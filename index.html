ขั้นตอนที่ 1: ดาวน์โหลดไฟล์ Excel Template (มีชีต Category_Reference อ้างอิงรหัสหมวดหมู่)

ไฟล์ประกอบด้วย 2 แผ่นงาน: แผ่นแรกสำหรับพิมพ์ข้อสอบ และแผ่นที่สอง (Category_Reference) อธิบายรหัสหมวดหมู่ทั้งหมด

ขั้นตอนที่ 2: อัปโหลดไฟล์ Excel (.xlsx) หรือ .csv ที่กรอกข้อสอบแล้ว

เชื่อมต่อ Google Sheets รับผลสอบสด

นักเรียนส่งข้อสอบปุ๊บ คะแนนจะถูกบันทึกลงตารางทันที และครูสามารถดึงคะแนนล่าสุดกลับเข้าระบบได้

ขั้นตอนการตั้งค่า (ทำครั้งเดียว):
  1. สร้าง Google Sheet ใหม่ 1 แผ่น (ว่างๆ ก็ได้ ระบบจะสร้างหัวตารางให้อัตโนมัติ)
  2. เมนู ส่วนขยาย (Extensions) → Apps Script แล้วลบโค้ดเดิมทั้งหมด วางโค้ดด้านล่างแทน
  3. กด Deploy → New deployment → Web app ตั้งค่า Execute as: Me, Who has access: Anyone
  4. คัดลอกลิงก์ Web app URL (ลงท้ายด้วย /exec) มาวางในช่องด้านล่าง แล้วกด "บันทึกการเชื่อมต่อ"
  5. กด "ทดสอบการเชื่อมต่อ" เพื่อส่งแถวทดสอบ แล้วเปิด Google Sheet ดูว่ามีแถวใหม่ขึ้นหรือไม่
ตั้งค่าไว้อยู่แล้ว? ให้กลับไปวางโค้ดใหม่ทับของเดิม แล้วกด Deploy → Manage deployments → ไอคอนดินสอ → เลือกเวอร์ชันใหม่ → Deploy อีกครั้ง เพื่อให้ระบบซิงค์ประวัติการทำข้อสอบข้ามเครื่องได้ (โค้ดเวอร์ชันนี้เพิ่มคอลัมน์ "AnswersSnapshot")
